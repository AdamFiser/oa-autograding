# Python

**Python** je *interpretovaný* programovací jazyk. ~~Python 2~~ už není podporován.

## Historie

### Významné události

- 1991: první veřejná verze
- 2008: vydání Pythonu 3
- Verze 3.12 přinesla
  1. rychlejší interpret
  2. lepší chybové hlášky
- 2020: konec podpory Pythonu 2

### Osobnosti a milníky

1. Guido van Rossum
2. Python Software Foundation
3. Konference PyCon
